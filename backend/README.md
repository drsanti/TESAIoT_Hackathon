# Bitstream Backend (Rust · v0.7)

Pure Rust headless Backend — **no Node.js**.

Download the zip for your OS, unzip, then **Start** (Windows) or `./start-bitstream-backend.sh` (macOS/Linux).

Docs: Bitstream-Studio `extension/docs/BITSTREAM_BACKEND_RUST.md` (ADR-019).
Node Backend zips (v0.6) are historical archive only.
