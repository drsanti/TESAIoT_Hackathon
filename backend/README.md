# Bitstream Backend (standalone)

Self-contained **headless** Backend for workshops and Marketplace thin VSIX users (**0.6.0**).

## Downloads

| Platform | File |
|----------|------|
| Windows x64 | [`bitstream-backend-0.6.0-win-x64.zip`](./bitstream-backend-0.6.0-win-x64.zip) |
| Linux x64 | [`bitstream-backend-0.6.0-linux-x64.zip`](./bitstream-backend-0.6.0-linux-x64.zip) |
| macOS Apple Silicon | [`bitstream-backend-0.6.0-darwin-arm64.zip`](./bitstream-backend-0.6.0-darwin-arm64.zip) |

## Install

1. Download the zip for your OS  
2. Unzip anywhere  
3. **Windows:** double-click **Start Bitstream Backend**  
   **macOS / Linux:** run `./start-bitstream-backend.sh`  
4. Open Bitstream Studio (Desktop or Marketplace thin VSIX) → Link  

No npm / Node install required.

See product docs: `Bitstream-Studio/extension/docs/BITSTREAM_BACKEND_STANDALONE.md`
