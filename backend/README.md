# Bitstream Backend (standalone)

Self-contained **headless** Backend for workshops and Marketplace thin VSIX users.

## Install

1. Download the latest `bitstream-backend-*-win-x64.zip`
2. Unzip anywhere
3. Double-click **Start Bitstream Backend**
4. Open Bitstream Studio (Desktop or thin VSIX) → Link

No npm / Node install required.

See product docs: `Bitstream-Studio/extension/docs/BITSTREAM_BACKEND_STANDALONE.md`
